Claude Code = AIが動く「ターミナルアプリ」でち
▼

Claude Code（クロード コード）は、Anthropic（アンソロピック）社がつくった AIプログラミングアシスタントでち。

ターミナル（＝黒い画面に文字を打つアプリ。「コマンドライン」とも言うよ）の中で動くでち。 チャットするみたいにAIに話しかけると、AIが：

  • コード（プログラム）を書いてくれる
  • ファイルを直接編集してくれる
  • バグ（プログラムの不具合）を見つけて直してくれる
  • Git（ギット＝コードの変更履歴を管理するしくみ）の操作もしてくれる
  • ウェブで調べ物もしてくれる

つまり「プログラマーの超優秀なアシスタント」がターミナルの中にいる感じでち！

Claude Codeを使うには、以下のどれかが必要でち：
・Claude Pro（クロード プロ）─ 月額 $20。いちばん安いプランでもClaude Codeが使えるよ！
・Claude Max（クロード マックス）─ 月額 $100（5倍）/ $200（20倍）。ヘビーに使いたい人向け。使用量の上限がProよりずっと多いでち
・APIキー─ 使った分だけお金がかかる方式。たくさん使うとMaxプランより高くなることも
インストール自体は無料だけど、動かすにはどれかが必要だよ。
💻コーディング支援
AIにプログラムを書いてもらう機能たちでち
✍️
コードを書いてもらう・直してもらう
▼

「こういう機能つくって」「このファイルにボタンを追加して」のように日本語で頼むだけでOKでち。 AIがコードを書いて、あなたのファイルに直接反映してくれるよ。

  • 新しいコードを書く ─ 「ログイン画面をつくって」
  • 既存のコードを修正 ─ 「この関数にエラー処理を追加して」
  • リファクタリング（＝コードの中身を整理してキレイにすること） ─ 「この処理を共通化して」
  • バグ修正 ─ 「このエラーが出るんだけど直して」
AIとのやりとり1回1回で「トークン」（＝文字数のようなもの）を消費するでち。 長いコードの読み書きほどたくさん消費するよ。
🔍
コードを読んで説明してもらう
▼

「このファイル何やってるの？」「この関数の意味を教えて」と聞くだけでち。 AIがコードを読んで、日本語でわかりやすく説明してくれるよ。

  • ファイル全体の概要説明
  • 特定の関数やクラスの動きの解説
  • 「なぜこう書いてあるのか」の理由を推測して教えてくれる
🧪
テストを書いてもらう・実行する
▼

テスト（＝プログラムが正しく動くか自動で確認するプログラム）を書いてもらえるでち。 「この関数のテストを書いて」と言えば、テストコードを作ってくれるよ。

  • テストコードの自動生成
  • テストの実行 ─ AIが npm test などのコマンドを実行してくれる
  • 失敗したテストの原因を調べて、修正案を出してくれる

サブエージェント（並列作業）
▼

サブエージェントとは、メインのAIが「分身」を作って、 複数の作業を同時にやらせる機能でち。

例えば「このプロジェクトにあるすべてのTODOコメントを探して」と頼むと、 AIが複数の分身を出して、フォルダごとに同時に探索してくれるよ。速い！

サブエージェントは複数のAIが同時に動くから、 トークン消費量がふつうより多くなるでち。 便利だけどたくさん使うと、使用量の上限（レートリミット）に早く達するかもしれないよ。

ファイルの作成・編集・削除
▼

AIがあなたのパソコン上のファイルを直接操作できるでち。

  • 作成 ─ 新しいファイルを作る（Write ツール）
  • 編集 ─ ファイルの一部を書き換える（Edit ツール）
  • 読み取り ─ ファイルの中身を見る（Read ツール）
  • 削除 ─ Bashコマンドで削除（確認あり）

⚠️ ただし、あなたの許可設定（後述する「自動承認」）によって、 勝手に編集できるか、毎回聞いてくるかが変わるよ。

ファイル検索（Glob / Grep）
▼

プロジェクト内のファイルやコードを探す方法が2つあるでち。

  • Glob（グロブ） ─ ファイル名のパターンで探す。 例：**/*.ts で「すべてのTypeScriptファイル」を一覧表示
  • Grep（グレップ） ─ ファイルの中身を文字で検索する。 例：TODO で「TODOと書いてあるファイル」を見つける

「〇〇って書いてあるファイルどこ？」と日本語で聞けば、 AIが自動でGlobやGrepを使って探してくれるよ。

Claude Codeはテキストファイルだけじゃなく、いろんなファイルが読めるでち。

  • 画像ファイル（PNG、JPGなど） ─ スクリーンショットを見せて「このエラー直して」ができる
  • PDFファイル ─ ドキュメントを読ませて内容を聞ける

Git（ギット）って何？
▼

Gitは、プログラムの「変更履歴」を記録するしくみでち。 ゲームのセーブデータみたいなもの！

  • コミット ─ 「今の状態をセーブする」こと
  • ブランチ ─ 「セーブデータを分岐させる」こと。本番に影響せず実験できる
  • プッシュ ─ セーブデータをインターネット上（GitHubなど）にアップロードすること
  • プル ─ インターネット上のセーブデータを自分のパソコンにダウンロードすること
  • マージ ─ 分岐したセーブデータを1つに合体させること

AIにGit操作をやってもらう
▼

Claude CodeはGit操作も全部やってくれるでち。

  • /commit ─ 変更を自動でコミット（セーブ）してくれる。メッセージもAIが考えてくれる！
  • ブランチ作成 ─ 「新しいブランチ作って」と言えばOK
  • 差分の確認 ─ 「何が変わった？」と聞けば教えてくれる
  • マージの競合解決 ─ コンフリクト（変更のぶつかり合い）も直してくれる

GitHub（ギットハブ）連携

GitHubは、Gitのセーブデータをインターネット上に保存するサービスでち。 Claude Codeは gh（GitHub CLI）コマンドを使ってGitHubも操作できるよ。

  • PR（プルリクエスト）作成 ─ 「自分の変更を本番に取り込んで」という申請を出すこと
  • PR レビュー ─ /review-pr で他の人のPRをAIに確認してもらえる
  • Issue（イシュー） ─ バグ報告や要望を確認して対応してくれる

ウェブ検索 & ページ取得
▼

Claude Codeはインターネットを検索したり、ウェブページを読むことができるでち。

  • WebSearch（ウェブサーチ） ─ 「〇〇の最新のドキュメント調べて」でインターネット検索
  • WebFetch（ウェブフェッチ） ─ 指定したURLのページの中身を読んで要約してくれる

AIの知識は学習した時点で止まっているから、最新情報が必要なときに便利でち！

CLAUDE.md（メモリーファイル）
▼

CLAUDE.mdは、AIに「このプロジェクトのルール」を覚えさせるためのファイルでち。 プロジェクトのルートフォルダ（一番上のフォルダ）に置くよ。

  • 「テストは必ずJestで書いて」などのルール
  • 「コミットメッセージは日本語で」などの約束
  • プロジェクトの構造や使っている技術の説明

/init コマンドで自動生成できるよ。 /memory コマンドで内容を確認・編集もできるでち。

🔐自動承認（パーミッション設定）
AIの行動をどこまで自動で許可するか決めるでち
🛡️
自動承認って何？なぜ大事？
▼

Claude Codeは、あなたのパソコンのファイルを直接編集したり、 コマンドを直接実行できるでち。これはとても強力だけど、 もし間違った操作をしたら大変だよね？

だから「どの操作を自動でやっていいか」「どの操作は毎回確認するか」を設定できるでち。 これが自動承認（パーミッション）の設定でち！

例えるなら：赤ちゃんにおもちゃを与えるとき、 「柔らかいおもちゃは自由に遊んでいいよ」「ハサミは大人に聞いてからね」 というルールを決めるのと同じでち！🍼

📊
3つの許可レベル
▼

Claude Codeには3つの許可モードがあるでち。

🟢 Suggest（サジェスト）─ いちばん安全

AIは何かする前に全部聞いてくるでち。 ファイルを読むのも、編集するのも、コマンドを実行するのも、全部あなたが「OK」と言ってから。 はじめてのひとにおすすめ！

🟡 Auto Edit（オートエディット）─ ふつう

ファイルの読み取りと編集は自動でやってくれるでち。 でもコマンドの実行（npm installとか、gitとか）は毎回確認してくるよ。 バランスがよくて多くのひとにおすすめ！

🔴 YOLO（ヨロ）─ 全自動⚡

ぜんぶ自動でやってくれるでち。確認なし！ 超高速で作業が進むけど、AIが間違ったコマンドを実行しちゃう可能性もあるよ。 Git管理下のプロジェクトで、ある程度慣れたひと向け。

※ YOLOは「You Only Live Once」（一度きりの人生、やっちゃえ！）の略でち。 まさに「やっちゃえ」モード 😎

変更するには /permissions コマンドを使うか、 設定ファイル ~/.claude/settings.json を編集するでち。

⚙️
個別の許可ルールも設定できる
▼

3つのモードとは別に、「この操作だけは自動で許可する」 「この操作だけはブロックする」という個別ルールも設定できるでち。

  • Allow（許可） ─ 例：npm test は毎回聞かなくて自動OK
  • Deny（拒否） ─ 例：rm -rf（全削除コマンド）は絶対に実行させない

ツール（AIが使う道具）ごとに設定できるよ：

  • Read（ファイル読み取り）
  • Edit（ファイル編集）
  • Write（ファイル作成）
  • Bash（コマンド実行）
  • WebSearch（ウェブ検索）
  • WebFetch（ページ取得）
📋プランモード
AIに「まず計画を立ててもらう」モードでち
🗺️
プランモードって何？
▼

ふつうにClaude Codeを使うと、AIはすぐにコードを書き始めるでち。 でも複雑な機能を作るときは「まず作戦を考えてから作業してほしい」よね？

プランモードをONにすると、AIは：

  • コードを書く前に作業計画書を作ってくれる
  • ファイルを読んだり検索したりして調査してくれる
  • でもファイルの編集・コマンド実行はしない（計画だけ！）
  • あなたが計画を確認して「OK」を出してから、初めて実行に移る

つまり「設計図を見せて → OKもらって → 建てる」の流れでち！🏗️

🔄
プランモードの使い方
▼

プランモードのON / OFF切り替え方法：

  • キーボードの Shift + Tab を押すと切り替わるでち
  • 画面の下のほうに「Plan mode」と表示が出るよ

プランモードの流れ：

🔍 調査
コードを読む
→
📝 計画作成
作業リストを作る
→
👀 あなたが確認
OKまたは修正依頼
→
🚀 実行
コードを書く！

こんなときにおすすめ：

  • 大きな機能追加のとき ─ まず全体像を把握したい
  • よくわからないコードベースのとき ─ まず調べてから作業してほしい
  • 失敗したくないとき ─ 計画を確認してから実行したい

基本コマンド（よく使う）
▼
コマンド何をするもの？
/help ヘルプ（使い方の説明）を表示する。困ったらまずこれ！
/clear 会話をリセットする。新しい話題を始めたいときに使う。今までの文脈（前の会話の内容）はクリアされるよ。
/compact 会話を圧縮する。長い会話でトークン（文字数のようなもの）を消費しすぎたときに使う。 AIが今までの会話を要約して、コンテキスト（文脈）の空き容量を増やしてくれるでち。
/commit 今の変更をGitにコミット（セーブ）してくれる。 AIがコミットメッセージ（変更の説明文）を自動で書いてくれるよ。
/fast ファストモードのON/OFF切り替え。 同じAIモデル（Claude Opus）で、出力速度が速くなるよ。 ※ 使うモデルは変わらないので、精度は同じでち。
/context 今のコンテキスト使用量を表示する。 「トークンをあとどれくらい使えるか」がわかるよ。上限に近づいたら /compact するタイミング！
/cost 今のセッション（今回の会話全体）で使ったコストを表示する。 APIキー利用の場合、どれくらいお金がかかったかわかるよ。

設定 & 管理コマンド
▼
コマンド何をするもの？
/init CLAUDE.mdファイルを自動生成する。 プロジェクトのルール・設定をAIに覚えさせるためのファイルでち。
/memory CLAUDE.mdの中身を表示・編集する。 AIに覚えておいてほしいルールを追加・変更できるよ。
/permissions 許可設定を管理する。 どの操作を自動で許可するか、どの操作をブロックするか設定できるでち。
/config Claude Codeの設定画面を開く。 テーマやモデルなど各種設定を変更できるよ。
/model 使うAIモデルを変更する。 Opus（最も賢い）、Sonnet（バランス型）、Haiku（軽量で高速）から選べるでち。
/theme 画面のテーマ（見た目）を変更する。 ダークモード（暗い画面）やライトモード（明るい画面）を切り替えられるよ。
/vim VimモードのON/OFF切り替え。 Vim（ヴィム＝昔からあるテキストエディタ）の操作方法で入力できるようになるでち。 知らなければ使わなくてOK！
/login Claude Codeにログインする。
/logout Claude Codeからログアウトする。
/status アカウントの状態（ログイン情報、プランの種類など）を確認する。
/doctor Claude Codeの健康診断。 インストールや設定に問題がないか自動でチェックしてくれるでち。

MCPサーバーって何？
▼

MCP（Model Context Protocol＝モデル コンテキスト プロトコル）は、 AIに「新しい道具」を与える仕組みでち。

ふつうのClaude Codeは、ファイル操作やウェブ検索ができるよね。 MCPサーバーを追加すると、それに加えてもっと色々できるようになるよ。

  • データベース操作 ─ SQLを実行してデータを取得・変更
  • Slack連携 ─ Slackにメッセージを送る
  • ファイルシステム拡張 ─ リモートサーバーのファイルを操作
  • その他 ─ 自分でMCPサーバーを作ることもできる！
MCPで接続する外部サービス（データベースやAPIなど）は、 それ自体に利用料がかかる場合があるでち。 Claude Code自体の費用とは別にかかるので注意してね。
