Claude Code = AIがおしごとしてくれる魔法のおへやでち
▼

Claude Code（クロード コード）は、Anthropic（アンソロピック）っていう会社がつくった すっごく頭のいいAIアシスタントでち🍼

ターミナル（＝黒いお部屋みたいな画面に文字をぽちぽち打つアプリでち。「コマンドライン」っていう別の名前もあるよ）の中で動くでち。 おしゃべりするみたいにAIに話しかけると、AIがいろんなことをやってくれるよ：

  • コード（＝コンピュータへのお手紙みたいなもの。プログラムのことでち）を書いてくれる
  • ファイル（＝パソコンの中にあるデータ）をそのまま直接いじってくれる
  • バグ（＝プログラムの「あれ？おかしいな」な部分）を見つけてなおしてくれる
  • Git（ギット＝「いつ何を変えたか」をぜんぶ記録してくれるしくみ）もやってくれる
  • インターネットで調べ物もしてくれる

つまり「なんでもできるすごいお友達」がパソコンの中にいる感じでち！🌟

Claude Codeを使うにはおかね（サブスク）が必要でち：
・Claude Pro（クロード プロ）─ 月々 $20（約3,000円くらい）。いちばんお手ごろでち！これでもClaude Code使えるよ🍼
・Claude Max（クロード マックス）─ 月々 $100（5倍）/ $200（20倍）。いーーっぱい使いたい人向けでち。使える量がProよりずっとずっと多いよ
・APIキー─ 使った分だけおかねがかかるやつ。使いすぎるとMaxより高くなっちゃうこともあるから気をつけてね
インストール（＝パソコンに入れること）自体はタダだけど、動かすにはどれかが必要だよ。

✍️
コードを書いてもらう・なおしてもらう
▼

「こういうの作ってでち！」「ここにボタン足してでち！」って日本語でお願いするだけでOKでち🍼 AIがコードを書いて、あなたのファイルにそのまま反映してくれるよ。すごいでち！

  • 新しく作る ─ 「ログイン画面つくってでち！」
  • 今あるのを直す ─ 「この関数（＝おしごとのかたまり）にエラー処理（＝失敗したときの対応）を足してでち！」
  • おそうじする（リファクタリング＝コードをキレイに整理すること） ─ 「ごちゃごちゃしてるからスッキリさせてでち！」
  • バグなおし ─ 「エラーが出てこわいでち…なおしてでち！」
AIとおしゃべりするたびに「トークン」（＝文字数みたいなもの）っていうのを使うでち。 長いコードを読み書きするほど、いっぱい使うよ。おしゃべりしすぎに注意でち！
🔍
「これなぁに？」って聞くと教えてくれるでち
▼

「このファイル何やってるのでち？」「ここの意味わかんないでち！」って聞くだけでち🍼 AIがコードを読んで、にほんごでやさしーく教えてくれるよ。

  • ファイルぜんたいの「ざっくりこういうことしてるよ」っていう説明
  • 「この部分はこういう動きをしてるよ」っていうくわしい解説
  • 「なんでこう書いてあるのかな？」の理由も推理して教えてくれるでち

テストも書いてくれるし動かしてくれるでち
▼

テストっていうのは「プログラムがちゃんと動くかな？」って自動でチェックしてくれるプログラムのことでち🍼 「この部分のテスト書いてでち！」って言えば作ってくれるよ。

  • テストのコードを自動で作ってくれるでち
  • テストを動かすのもやってくれる ─ AIが npm test っていうおまじないを唱えてくれるよ
  • テストが失敗しちゃっても「ここが原因でち！」って調べてなおしてくれるでち
🤖
分身の術！サブエージェントでち
▼

サブエージェントっていうのは、AIが「分身の術」を使って、 いっこのおしごとをみんなで同時にやっちゃう機能でち🍼

たとえば「このプロジェクトの中から"TODO"って書いてあるところぜんぶ探してでち！」って頼むと、 分身がいっぱい出てきて、あっちこっちのフォルダを同時に探してくれるよ。はやい！すごい！

分身がいっぱい動くから、トークン（文字数みたいなもの）をふつうよりいっぱい使っちゃうでち。 便利だけど使いすぎると、使える量の上限（レートリミット＝「今日はここまで！」の線）にすぐ届いちゃうかもでち。

📝
ファイルを作ったり、なおしたり、消したりできるでち
▼

AIがあなたのパソコンの中にあるファイルを直接さわれるでち🍼

  • つくる ─ 新しいファイルをポンッと作るよ（Writeツールっていうのを使うでち）
  • なおす ─ ファイルの中身の一部をちょちょいと書き換えるよ（Editツール）
  • よむ ─ ファイルの中身をのぞいて見るよ（Readツール）
  • けす ─ ファイルを消すこともできるよ（消す前にちゃんと「いい？」って聞いてくるでち）

⚠️ ただし！あなたが決めたルール（あとで説明する「自動承認」っていうやつ）によって、 勝手にやっていいか、毎回「やっていい？」って聞いてくるかが変わるでち。

🔎
ファイルを探すのも得意でち（Glob / Grep）
▼

プロジェクト（＝作ってるもの全体）の中からファイルやコードを探す方法が2つあるでち🍼

  • Glob（グロブ） ─ ファイルの名前で探すやつでち。 たとえば **/*.ts って書くと「TypeScript（タイプスクリプト）っていう種類のファイル、ぜんぶ見せて！」って意味になるよ
  • Grep（グレップ） ─ ファイルの中身を文字で探すやつでち。 たとえば TODO って書くと「中にTODOって書いてあるファイルはどこ！？」って探してくれるよ

でもむずかしい名前は覚えなくて大丈夫！ 「〇〇って書いてあるファイルどこでち？」って日本語で聞けば、 AIが勝手にGlobやGrepを使って探してくれるでち。べんりー！

Git（ギット）ってなぁに？
▼

Git（ギット）は、プログラムの「いつ何を変えたか」をぜーんぶ記録してくれるしくみでち🍼 ゲームのセーブデータみたいなもの！ミスしても「前のセーブに戻す」ができるでち！

  • コミット ─ 「今の状態をセーブ！」ってすること。ゲームでいうセーブポイントでち
  • ブランチ ─ 「セーブデータを分けて別ルート作る！」ってこと。本番に影響しないで実験できるよ
  • プッシュ ─ セーブデータをインターネット上（GitHubとか）に「えいっ！」ってアップロードすること
  • プル ─ インターネット上にあるセーブデータを自分のパソコンに「よいしょ！」ってダウンロードすること
  • マージ ─ 分かれたセーブデータを「がっちゃんこ！」って1つに合体させること

Claude Codeはインターネットで検索したり、ウェブページを読むこともできるでち🍼

CLAUDE.md ─ AIへのおやくそくメモでち
▼

CLAUDE.md（クロード・エムディー）は、AIに「このプロジェクトのおやくそく」を覚えさせるためのメモ帳でち🍼 プロジェクトの一番上のフォルダに置いておくよ。

  • 「テストはJestっていうやつで書いてね！」みたいなルール
  • 「セーブのメッセージは日本語で書いてね！」みたいなおやくそく
  • 「このプロジェクトはこういう構造だよ」っていう説明

/init っていうコマンドで自動で作ってくれるよ。 /memory っていうコマンドで中身を見たりなおしたりもできるでち。かんたん！

AIにどこまで勝手にやっていいか決めてあげるでち🍼
🛡️
自動承認ってなぁに？なんで大事なのでち？
▼

Claude Codeは、あなたのパソコンのファイルを直接いじったり、 コマンド（＝パソコンへの命令）を直接実行できちゃうでち。 すっごくパワフルだけど、もし間違えたらたいへんだよね？こわいでち…🍼

だから「何は勝手にやっていいよ」「何はちゃんと聞いてね」っていうルールを決められるでち。 これが自動承認（パーミッション）でち！おるすばんのおやくそくみたいなものだよ。

たとえばね：ばぶちゃんにおもちゃをあげるとき、 「やわらかいおもちゃは好きにあそんでいいよ〜」「ハサミは絶対ダメ！大人に聞いてから！」 ってルールを決めるでしょ？それとおんなじでち！🍼

📊
おるすばんルールは3種類あるでち
▼

Claude Codeのおるすばんルール（許可モード）は3つあるでち🍼

🟢 Suggest（サジェスト）─ いっちばん安全！

AIは何かする前にぜーんぶ聞いてくるでち。 ファイルを見るのも、書きかえるのも、コマンドを動かすのも、ぜんぶ「いい？」って聞いてくるよ。 はじめてのばぶちゃんはこれにするでち！

🟡 Auto Edit（オートエディット）─ ちょうどいいやつ

ファイルを見るのと書きかえるのは勝手にやってくれるでち。 でもコマンド（npm installとか、gitとか、パソコンへの命令）は「やっていい？」って毎回聞いてくるよ。 ちょうどいいバランスだから、みんなにおすすめでち！

🔴 YOLO（ヨロ）─ ぜんぶおまかせ⚡

なーんにも聞かないで、ぜんぶ勝手にやるでち。確認ゼロ！ めっちゃ速いけど、AIがうっかり変なコマンド動かしちゃうかも…🙈 Git（セーブ機能）があるプロジェクトで、慣れてきたひと向けでち。

※ YOLOは「You Only Live Once」（人生一度きり、やっちゃえ〜！）の略でち。 まさに「えいやっ！」モード😎

変えたいときは /permissions って打つか、 ~/.claude/settings.json っていう設定ファイルを書きかえるでち。

⚙️
こまかーいルールも決められるでち
▼

3つのモードとは別に、「これだけはOK！」「これだけは絶対ダメ！」っていう こまかいルールも決められるでち🍼

  • Allow（おっけー！） ─ 例：npm test（テスト実行）は聞かなくていいよ〜自動でやっていいでち
  • Deny（だめー！） ─ 例：rm -rf（ぜんぶ消しちゃうコマンド）は絶対やらせないでち！

AIが使う道具（ツール）ごとに決められるよ：

  • Read（ファイルを読む）
  • Edit（ファイルをなおす）
  • Write（ファイルを新しく作る）
  • Bash（パソコンにコマンドを実行させる）
  • WebSearch（インターネットで検索する）
  • WebFetch（ウェブページを読む）

🗺️
プランモードってなぁに？
▼

ふつうにClaude Codeを使うと、AIはいきなりコードを書き始めるでち。 でもむずかしいおしごとのときは「ちょっと待って！まず作戦考えてからにしてでち！」ってなるよね？

プランモードをONにすると、AIは：

  • コードを書く前にまず「こういう順番でやるよ！」っていう作戦表を作ってくれるでち
  • ファイルを読んだり検索したりして下調べしてくれるでち
  • でもファイルをいじったりコマンドは動かさない（作戦だけ！手は出さないでち！）
  • あなたが作戦を見て「いいよ！」って言ってから、はじめておしごと開始でち

つまり「設計図みせて → いいね！ → つくって！」の流れでち！🏗️

MCPサーバーってなぁに？
▼

MCP（えむしーぴー）は、AIに「新しい道具」を持たせてあげるしくみでち🍼 正式名称は「Model Context Protocol（もでる こんてきすと ぷろとこる）」っていうけど、覚えなくて大丈夫！

ふつうのClaude Codeは、ファイルを読んだりインターネットで調べたりできるよね。 MCPサーバーをつなげると、それにプラスしてもっといろんなことができるようになるでち！

  • データベース操作 ─ データの入れ物に「このデータちょうだい！」ってお願いできるでち
  • Slack連携 ─ Slack（チャットアプリ）にメッセージを送れるでち
  • 遠くのパソコンのファイル ─ 自分のパソコンじゃないところのファイルも見れるでち
  • その他 ─ じぶんでオリジナルの道具を作ることもできるよ！すごい！
MCPでつなげる外のサービス（データベースとかAPI とか）は、 それ自体に利用料がかかることもあるでち。 Claude Codeのおかねとは別でかかるから気をつけてね！

📱スマホで使う裏技
パソコンなくてもClaude Codeが使えちゃうひみつの方法でち🤫
🤫
スマホだけでClaude Codeを使うひみつ
▼

じつは…Claude Codeはスマホだけでも使えちゃうでち！🤫 パソコンがなくても、GitHubとClaudeのサイトがあればOKだよ。ないしょの裏技でち🍼

やりかたはこうでち：

  • ① まず ─ スマホでGitHub（猫ちゃんマークのサイト）にログインするでち
  • ② つぎに ─ 「NEW」ボタンをぽちっ！Create a new repositoryで空っぽのリポジトリ（＝おしごとの保存場所）を作るでち
  • ③ それから ─ Claudeのサイトにある「コード」っていうところを押して、Claude Codeを開くでち
  • ④ そして ─ 「新規セッション」をぽちっ！
  • ⑤ つづいて ─ GitHubの猫ちゃんマークがあるから押して、さっき作った空っぽのリポジトリを選ぶでち
  • ⑥ あとは ─ ふつうにClaude Codeとおしゃべりして指示を出すだけでち！かんたん！
  • ⑦ さいごに ─ リポジトリの設定でGitHub Pagesを公開にすれば、そのままWebサイトのリンクになるよ

つまりスマホ → GitHub → Claude Code → Webサイト完成！ぜーんぶスマホだけでできちゃうでち！すごくない！？🌟

🖼️ サムネイル画像を勝手に作らせちゃうでち

リンクをDiscordやTwitterに貼ったとき、ぺろっとプレビュー画像が出るとかっこいいよね？ こんなふうにお願いすればAIが勝手に作ってくれるでち：

「リンクをコピーするとリンクだけで出てくるでち。他のリンクはDiscordとかに貼ったらサムネ画像が出てくるでち。サムネ画像…憧れるでち。対策してでち」

→ こう言うだけで、OGP（＝リンクにサムネ画像をつける設定）をAIが自動で追加してくれるでち！かしこい！

💾 データを消えないようにするでち

Webアプリ（ブラウザで動くアプリ）を作るとき、こう伝えるとデータが消えなくなるでち：

  • 「データはlocalStorageに保存して、リロードしても消えないようにしてでち」
  • 「データの保存にはIndexedDBを使っていいよ」

こうするとSafari（iPhoneのブラウザ）で更新ボタン押してもデータが残るでち！やったー！

※ プライベートブラウズ（こっそりモード）だとブラウザを閉じたとき消えちゃうことがあるよ

おかねに注意でち！ Claude Codeを使うとき1Mモデル（100万トークンのやつ）は選ばないでね！ 20万トークンを超えるとサブスクに含まれない追加のおかねが発生しちゃうでち。こわい！
スマホの場合は設定の「追加使用量」のチェックをはずしておくのがいちばん安全だよ。 これでうっかり課金されるのを防げるでち🍼
